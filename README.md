# 数学闯关岛

给二年级小朋友的数学闯关练习 App（Flutter / Android），**纯离线运行**，无需联网、无需账号。

## 功能

- **黏土海盗岛风（照着参考图重做的画风）**：粉蓝天空 + 蓬蓬云 + 左上角太阳光晕，青绿色海面带亮带波光；整座岛是**沙滩 + 礁石 + 白浪 + 草地**一段段叠出来的立体长岛，岛边种椰子树（弯树干、带节、一圈叶子、两个椰子）、圆顶小屋、灌木、石头，沙滩上散着贝壳和粉色珊瑚；**山顶立着一座灯塔**（白塔身 + 两圈橘条纹 + 暖黄灯室 + 橘色圆顶 + 光晕）。路面是浅色石板路，关卡是彩色圆台。
- **真 3D 透视的岛路**：首页用的是真透视相机——镜头站在路上往前看，屏幕 `y = 地平线 + 焦距×镜头高 / 距离`、`x = 屏幕中心 + 焦距×横向偏移 / 距离`，所以**越远的关在上面、画得越小，越近的关在下面、画得越大**，路自己收敛到地平线（`MapLayout.projectY / projectX / scaleOf`）。远景雾化成一条白带，峰顶灯塔只在天边露一个小尖，走到最后几关它会一点点变大。
- **沿着路一直往上走**：手指往下扒拉 = 往前走，一关一关朝镜头涌上来再擦身而过，松手还有惯性；每关一左一右错开摆在路上，路边一圈彩色鹅卵石、椰子树、圆顶小屋、珊瑚、贝壳，台阶和房子都带接触阴影，所以像真的站在地上。
- **走不完的路**：镜头后面是走过的、前面是还没走到的；远处的关卡淡出在雾里（`_fadeFor`），一路往上爬不封顶。通关的台阶变绿并亮星，当前这一关发光浮动，点台阶直接进关，右下角 🎯 一键回到当前关。
