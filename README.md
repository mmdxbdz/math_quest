# 数学闯关岛

给二年级小朋友的数学闯关练习 App（Flutter / Android），**纯离线运行**，无需联网、无需账号。

## 功能

- **黏土海盗岛风（照着参考图重做的画风）**：粉蓝天空 + 蓬蓬云 + 左上角太阳光晕，青绿色海面带亮带波光；整座岛是**沙滩 + 礁石 + 白浪 + 草地**一段段叠出来的立体长岛，岛边种椰子树（弯树干、带节、一圈叶子、两个椰子）、圆顶小屋、灌木、石头，沙滩上散着贝壳和粉色珊瑚；**山顶立着一座灯塔**（白塔身 + 两圈橘条纹 + 暖黄灯室 + 橘色圆顶 + 光晕）。路面是浅色石板路，关卡是彩色圆台。
- **沿着岛上的路一直往上走**：首页是一条**向前延伸的蜿蜒岛路**——沙滩圈 + 礁石 + 白浪 + 草地，路面是浅色石板路；手指往下扒拉，上面的关卡就一节节下来（镜头跟着手指走），一关一关往山上爬，山顶立着灯塔（白塔身 + 橘条纹 + 暖黄灯 + 橘色圆顶）。岛边椰子树、圆顶小屋、珊瑚、贝壳、草丛礁石都在。
- **前面还没走到的路藏在云雾里**：脚下往上只露出 2~3 关，再往上的路被一排胖云挡着；每通关几关，云雾就退上去、路再往上延伸一截——所以越玩路越长，一直能往上走。通关的台阶变绿并亮星，当前这一关发光浮动，点台阶直接进关，右下角 🎯 一键回到当前关。
