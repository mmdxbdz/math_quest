# 数学闯关岛

给二年级小朋友的数学闯关练习 App（Flutter / Android），**纯离线运行**，无需联网、无需账号。

## 功能

- **立体海岛地图**：首页是一整座会动的长岛，**路线从最下面的第 1 关往上延伸**，一级台阶一关，越往后爬得越高；地图跟着手指走（**手指往下扒拉，上面的第 2 关、第 3 关就一节节下来**）；整个画面带透视（越往上越远越高），台阶是立体圆台，岛有厚度和倒影，海面、云、飞鸟、太阳都在动。78 个关卡按顺序解锁，通关的台阶变绿并亮星，当前这一关会发光浮动；点台阶直接进关，右下角 🎯 一键回到当前关。
- **按课时出题**：每个课时有专属题目生成器，题目**每次随机生成**，不是固定题库。
- **今日任务**：家长设置"学到哪一课"后，每天生成 8 题精准任务（当前课时新课 + 到期错题 + 正确率最低的知识点专项）。
- **不许蒙**：每道题第一次答错即锁定选项并跳过，在本轮末尾的「🔁 复习」再考一次；答错的题自动进错题本。
- **知识点诊断**：家长面板按知识点显示正确率与「一次答对率」，低于 60% 标 ⚠️，今日任务自动优先练短板。
- **错题本 + 间隔复习**：答错次日 → 第 3 天 → 第 7 天 → 第 15 天回炉，连续 4 轮答对才算掌握。
- **思维小挑战**：找规律 / 巧算 / 推理三类动脑题，全对得金银徽章。
- **北极熊小宠物（不说一句台词）**：第一次进游戏，小北极熊自己从屏幕下方跳出来，凑到跟前**舔屏幕**（舌头 + 爱心 + 啵啧声），点「❤️ 抱抱它」就正式收养。之后每次回到首页，它都会自己跳出来舔她一口再跳走；饿了就在头顶飘一条抖动的 🐟（**北极熊吃鱼**，各物种吃各自的：小猫 🐟、小兔 🥕、小狗 🍖、熊猫 🎋、小熊 🍯、小猪 🌽…）。不弹字、不说话，只用动作和声音撒娇。家里也一样：一进门它就跑过来舔两下，饿了会自己跑到饭碗边上。名字、状态这些界面文字照旧。
- **闯关攒粮食 + 越长越胖（喂饭不再静默）**：每闯一关，**食盒里多一份粮食**（结算页会告诉你食盒里还剩几份），不会再偷偷替它吃掉。喂饭要娃自己来：去宠物住所点「🍚 喂它」（或者直接点房间里的食盒），它就**自己一路小跑到食盒边，低头一口一口吃**（嘴巴张开、碎屑飞、碗里的余粮数字当场变少）；吃到 3 口长大一阶，共 5 阶（小奶崽 → 会走啦 → 圆滚滚 → 胖乎乎 → 超级胖），体型和肚子肉眼可见地变大。食盒空了它就饿（头顶飘着爱吃的东西），点「🧺 装食盒」免费装满（最多 3 份），靠闯关也能补。
- **它真的会吃、会喝、会上床睡**：宠物不是一张大头像——走路时四只小爪一前一后、站着会呼吸、偶尔眨眼。
  - 「💧 喝水」或点水碗：跑到右边的水碗边，低头舔几口水（啵啧声）。
  - 「🌙 睡觉」或摸它：自己走到床边**躺下**（身体压扁、眼睛眯成弯弯，头顶飘 z z z），点「☀️ 叫醒」或再摸一下就起来。
  - 吃饭、喝水、睡觉全有动作和声音，没有一句台词。
- **越闯关，朋友越多（一共 9 种）**：除了开场的北极熊雪球，**每闯满 6 关就有一位新朋友住进岛上的一间宠物房**（第 6、12、18、24、30、36、42、48 关各一间：小猫/小兔/小狗/熊猫/小熊/小狐狸/小猪/小青蛙，顺序固定、不重复）。
  - **宠物房就开在"该领新宠物的那一关"和"下一关"中间的小路上**：屋顶、房身、拱门，门框上挂着一圈头像 = 这间房住的是谁（小猫 🐱 / 小兔 🐰 …），一眼就知道下一只是什么。
  - 还没领到：头像是灰的，门上挂 🔒；**下一间要住进来的那间，门框套一圈金圈 + 🎁**，一看就知道"再往上闯就到了"。
  - 领到手：头像亮起来，点这间宠物房直接进宠物住所。闯到那一关时，它会自己跑出来（舔一口 + 爱心），点「❤️ 领它回家」就正式住下。
  - 宠物住所里有「我的朋友们」一排头像，**点谁就换谁陪你闯关**（名字、帽子、成长都各自独立）。
- **闯关掉小礼品，布置宠物小家**：每闯一关还掉一件家具——小窝（竹篮窝 / 小沙发 / 小帐篷 / 小木床）、枕头（小熊抱枕 / 云朵枕头…）、家电（小电视 / 台灯 / 风扇 / 冰箱 / 平板）、摆件（仙人掌 / 皮球 / 气球 / 相框 / 盆栽），共 18 件。全收齐后改成金币奖励。掉落时会自动摆进小家，也能在住所里随时换位置、收起来。
- **宠物住所**：随时可以点底部 🐾 去看望它——一进门它就跑过来舔两下、爱心飘起来，之后在房间里来回走，可以摸它、**给它改名**、**戴帽子**（帽子按成长阶段解锁），还能重新布置它的小家。
- **自由布置小家**：家具**按住就能拖到自己喜欢的位置**，位置会记住；点格子或礼物箱里的家具可以随时换上、收起。
- **房间越收集越多**：客厅（默认）→ 卧室（收集 4 件家具解锁，晚上有小夜灯）→ 雪屋（收集 10 件解锁，有暖炉和冰雕），每个房间独立布置。
- **合影卡**：掉到「合影相框」摆进房间后，**点一下相框就弹出一张合影画**（雪地、扎小揪揪的她、戴着帽子的北极熊、飘着的爱心，下面写着「我和雪球的合影」和日期，还会念一句「咔嚓！」）——不用相机、不用权限。
- **一天没喂会饿**：今天是新的一天还没喂它，它就会饿得直叫：**住所里它会一路小跑到饭碗边上，脑袋上冒「咕噜噜…」**，饭碗变成 🍖；首页有提醒条（点一下直接去闯关），进来时还会语音喊她。
- **语音鼓励 + 音效**：中文语音鼓励（诙谐语气）；答对有全屏烟花和程序合成的"嗖""嘭"音效。
- **奖惩制度**：全对 +100、90 分以上 +50、80 分以下 -50、70 分以下 -100，达标自动提醒家长执行，家长面板记录「已实施」。
- 所有进度只存手机本地，数据不出设备。

## 项目结构

```
lib/
  main.dart                 应用入口（含全局错误兜底）
  app_info.dart             应用名 / 版本 / 隐私说明文案

  models.dart               Question / Lesson / Unit / RewardRecord 数据模型
  store.dart                进度存档（shared_preferences，含宠物）

  speech.dart               中文语音鼓励（flutter_tts）

  content/

    challenge.dart          思维小挑战关卡表

  gen/                      各主题题目生成器（纯 Dart，可单测）
    util.dart               随机 / 干扰项 / 口诀工具
    gen_stats.dart          数据整理
    gen_div1.dart           平均分 / 表内除法（2~6）
    gen_motion.dart         图形的运动
    gen_div2.dart           表内除法（7~9）
    gen_mixed.dart          混合运算
    gen_remainder.dart      有余数的除法
    gen_bignum.dart         千 / 万以内的数
    gen_weight.dart         克与千克
    gen_reasoning.dart      推理
    gen_challenge.dart      找规律 / 巧算 / 推理挑战
  screens/                  首页（海岛地图）/ 答题 / 结算 / 宠物住所 / 错题本 / 家长 / 挑战
  widgets/                  海岛地图、数字键盘、星星爱心、水泡泡、烟花
test/                       生成器、复习、奖惩、挑战、宠物、回归测试
```

## 开发环境

构建脚本 `build.ps1` 会**自动探测**目录（也可用环境变量 `FLUTTER_HOME` / `JDK_HOME` / `ANDROID_SDK_ROOT` 指定）：

- Flutter SDK：`G:\dev\flutter`（其次 `D:\dev\flutter`）
- JDK 17：`G:\dev\jdk17`（其次 `D:\dev\jdk17`）
- Android SDK：`G:\dev\android-sdk`（其次 `D:\dev\android-sdk`）

## 构建与安装到手机

```
powershell -File build.ps1
```

或手动：

```
$env:PUB_HOSTED_URL = 'https://pub.dev'
flutter pub get
flutter analyze          # 静态检查
flutter test             # 单元测试
flutter build apk --release
```

产物在 `build\app\outputs\flutter-apk\app-release.apk`。

安装到手机：
1. 把 APK 传到手机（微信文件传输助手 / 数据线 / 网盘均可）。
2. 手机上点开 APK，允许"安装未知来源应用"。
3. 装好后桌面出现「数学闯关岛」图标，点开即用，全程无需联网。

（手机打开 USB 调试连电脑时，也可以直接 `flutter install`。）

## 教学范围与版权说明

- 题库由程序**随机生成**，题目文字为本项目原创；知识点范围参考《义务教育数学课程标准》（二年级），**不使用任何教材的原文、例题、练习题与插图**。
- 应用名称、界面文案、课时标题均为自拟（如"一样多""口诀找商""分不完的余数"），**不使用教材品牌名与章节名**，不隶属于也不关联任何教材出版机构。
- 知识结构按"数的认识 / 除法 / 混合运算 / 图形的运动 / 测量 / 数据 / 推理"类目组织，便于家长按学校进度挑选课时。

## 隐私说明

- 不收集任何个人信息：无账号、无联网、无统计、无广告。
- 学习数据仅存本机，家长面板可一键重置。
- 完整政策见 `PRIVACY.md`；应用内「家长面板 → 关于与隐私」也可查看。

## 升级 / 换机：进度一定不能丢

- **升级新版本：直接覆盖安装，千万别先卸载**。卸载会把本机数据（星星、金币、错题、宠物）一起清掉。包名 `com.family.math_quest` 不变、版本号往上加（`pubspec.yaml` 的 `version: 1.0.0+2`，`+` 后面是 versionCode）、签名用同一把 `android/app/build.gradle.kts` 里的 debug key，所以手机把它当"升级"，数据原样保留。
- 存档兼容：新版本读老存档时，缺的字段一律给默认值（例如老存档没有 `food`，就直接给满一盒粮食），星星 / 金币 / 错题 / 宠物 / 家具照旧读进来；`test/migration_test.dart` 专门守这条线。
- 兜底：读存档前先把**上一份能正常读的存档**写进 `progress_v1_backup`，主存档万一坏了（JSON 截断等）会自动回退备份，绝不把娃的进度清零。
- 多一道保险（换手机、重装时用）：**家长面板 → 💾 存档备份 → 复制存档码**，把那串字存到微信/备忘录；新手机上点**粘贴恢复**就接着玩。存档码就是 base64 的整份存档，不含任何网络请求。

## 调整难度 / 内容

- 每关题量：家长面板可直接改（6/8/10）。
- 想重看开头的宠物动画：**家长面板 → 🐻 宠物动画**
  - 「再看一遍动画」：不删任何数据，回首页就把「小熊跳出来舔她 + ❤️ 抱抱它」整套再演一遍（你自己的手机上反复测效果用这个）。
  - 「清空宠物」：宠物、成长进度、收到的家具清掉，回到真正的第一次（关卡星星不动）。
  - 不想让娃看到就把这个按钮留着自己按——她在自己那台新装的手机上，第一次打开自然就会演一遍。
- 新朋友多久来一间宠物房：改 `lib/pets.dart` 的 `kPetUnlockEveryLevels`（现在 6 关一间），顺序改 `kPetUnlockOrder`。
- **食盒容量（一次最多存几份粮食）**：`lib/pets.dart` 的 `kFoodBowlCap`（现在 5）。喂一口扣一份、成长 +1；吃几口长大一阶看 `kFeedsPerStage`。
- **宠物动作**：`pets.dart` 的 `PetAvatar` 支持 `pawPhase`（走路）/ `dip`（低头）/ `eating` / `drinking` / `sleeping` / `blink`；`screens/pets_house.dart` 的 `_PetActor` 用一小段"动作脚本"（`_walkTo` / `_chew` / `_sip` / `_lie` / `_wake`）把它串起来，想加新动作就往 `_runAct` 里加几步。
- **题目重复**：`lib/gen/util.dart` 的 `dedupe` 只留题干不重复的题、**不够就少出几道，绝不重复补位**；`test/variety_test.dart` 会检查每个课时每个阶段都能生成 ≥10 道不重复题、选项不重复、答案在选项里。想让某个课时更多花样，就在对应生成器里多写几种问法的 `switch (t % n)`。
- 数字范围、题型比例：改 `lib/gen/` 里对应生成器的 `ri(...)` 参数。
- 新增课时：在 `curriculum.dart` 的 `units` 里加一条 `Lesson(id, 标题, 生成函数)`。
- 改名：改 `lib/app_info.dart` 的 `AppInfo.name`，以及 `android/app/src/main/AndroidManifest.xml` 的 `android:label`。
