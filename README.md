# 数学闯关岛

给二年级小朋友的数学闯关练习 App（Flutter / Android），**纯离线运行**，无需联网、无需账号。

## 功能

- **黏土海盗岛风（照着参考图重做的画风）**：粉蓝天空 + 蓬蓬云 + 左上角太阳光晕，青绿色海面带亮带波光；整座岛是**沙滩 + 礁石 + 白浪 + 草地**一段段叠出来的立体长岛，岛边种椰子树（弯树干、带节、一圈叶子、两个椰子）、圆顶小屋、灌木、石头，沙滩上散着贝壳和粉色珊瑚；**山顶立着一座灯塔**（白塔身 + 两圈橘条纹 + 暖黄灯室 + 橘色圆顶 + 光晕）。路面是浅色石板路，关卡是彩色圆台。
- **一屏一座圆岛**：首页现在是一整块**圆滚滚的岛**放在海面上——沙滩圈 + 礁石 + 白浪 + 圆鼓鼓的草地，关卡从岛最下面的第 1 关开始，**一圈圈盘上去**，最后一关到山顶，山顶立着灯塔；岛的边缘种着椰子树、小屋、珊瑚、贝壳，草丛里还有礁石。左右滑动（或点左上/右上箭头）可以翻到上一座 / 下一座岛，顶部木牌写着「第 3/10 座岛 · 主题名」。
- **课文单元 = 一座岛**：78 关拆成 10 座岛（一个主题单元一座，6~12 关），一屏就能看完整座岛，不用再往上爬很久；上次玩到的那座岛会自动出现，通关的台阶变绿并亮星，当前这一关发光浮动；点台阶直接进关，翻到别的岛时右下角 🎯 一键回到现在这座岛。
